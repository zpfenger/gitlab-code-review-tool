## 1. 概述

本数据库用于存储 GitLab 代码审查工具的所有业务数据，包括项目配置、系统设置、任务执行日志、提交记录、Webhook 审查结果、用户权限以及人员能效统计。

**数据库类型**: SQLite  
**文件位置**: `./data/config.db`  
**ORM 框架**: SQLAlchemy (declarative_base)

---

## 2. 技术栈

| 组件 | 技术 | 说明 |
|------|------|------|
| 数据库 | SQLite 3 | 轻量级嵌入式数据库 |
| ORM | SQLAlchemy | Python SQL 工具包和 ORM |
| 连接池 | SessionLocal | 单连接模式，适配 SQLite |
| 外键支持 | PRAGMA foreign_keys=ON | 每次连接自动启用 |

## 4. 表结构详解

### 4.1 基础模型

所有业务表继承自 `BaseModel`，自动包含以下字段：

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | Integer | PK, AUTOINCREMENT | 主键 |
| created_at | DateTime | NOT NULL | 创建时间 (UTC) |
| updated_at | DateTime | NOT NULL | 更新时间 (UTC，自动更新) |

---

### 4.2 projects - 项目配置表

**表名**: `projects`  
**说明**: 存储 GitLab 项目的基本配置信息

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | Integer | PK | - | 主键 |
| name | String(100) | NOT NULL, UNIQUE | - | 项目名称 |
| gitlab_url | String(500) | - | NULL | GitLab 地址 (为空使用全局配置) |
| project_id | Integer | NOT NULL, UNIQUE | - | GitLab 项目 ID |
| description | Text | - | NULL | 项目描述 |
| target_branches | Text | - | NULL | 目标分支列表 (逗号分隔) |
| access_token | String(500) | - | NULL | 访问 Token (加密存储) |
| exclude_branches | Text | - | '' | 排除分支列表 (逗号分隔) |
| svn_url | String(500) | - | NULL | 项目专属 SVN 路径 |
| svn_username | String(100) | - | NULL | 项目专属 SVN 用户名 |
| svn_password | String(500) | - | NULL | SVN 密码 (加密存储) |
| wecom_enabled | Boolean | - | False | 企业微信通知开关 |
| wecom_webhook_url | String(500) | - | NULL | 企业微信 Webhook URL (加密存储) |
| is_active | Boolean | NOT NULL | True | 是否启用 |
| created_at | DateTime | NOT NULL | UTC now | 创建时间 |
| updated_at | DateTime | NOT NULL | UTC now | 更新时间 |

**关系**:
- `task_logs` → TaskLog (1:N, CASCADE)
- `commit_records` → CommitRecord (1:N, CASCADE)

### 4.4 task_logs - 任务执行日志表

**表名**: `task_logs`  
**说明**: 记录每次代码审查任务的执行情况

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | Integer | PK | - | 主键 |
| project_id | Integer | FK(projects.id), NOT NULL | - | 关联项目 |
| project_name | String(100) | - | NULL | 项目名称（冗余，避免 JOIN） |
| task_type | String(20) | NOT NULL | - | 任务类型: daily/weekly/monthly |
| trigger_type | String(20) | NOT NULL | - | 触发类型: scheduled/manual |
| trigger_user | String(100) | - | NULL | 手动触发时的用户 |
| status | String(20) | NOT NULL | - | 状态: running/success/failed |
| start_time | DateTime | NOT NULL | utcnow | 开始时间 |
| end_time | DateTime | - | NULL | 结束时间 |
| branches_processed | Integer | - | 0 | 处理的分支数 |
| commits_processed | Integer | - | 0 | 处理的提交数 |
| reports_generated | Integer | - | 0 | 生成的报告数 |
| error_message | Text | - | NULL | 错误信息 |
| details | Text | - | NULL | 详细日志 (JSON) |
| created_at | DateTime | NOT NULL | UTC now | 创建时间 |
| updated_at | DateTime | NOT NULL | UTC now | 更新时间 |

**关系**:
- `project` → Project (N:1, CASCADE)

**计算属性**:
- `duration`: 自动计算执行耗时，格式化为 `Xs` / `XmXs` / `XhXmXs`
